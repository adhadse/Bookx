The Aozora file is not an EPUB: `build-aux/make-vertical-epubs.py aozora SRC.html OUT.epub` turns chapters 1 to 3 into a
`vertical-rl` EPUB (one `<p>` per line of the source, the ruby kept, `page-progression-direction="rtl"`), which
`build-aux/session-tests.sh` writes to `~/.cache/bookx-testbooks/vertical-neko.epub`. The same script generates
`vertical-synthetic.epub` (original sentences written for the test: ruby, tate-chu-yoko, punctuation in a row, Latin text
turned and upright, a picture, a `vertical-lr` chapter in Traditional Chinese, a horizontal chapter with ruby) and, for the
budget scenario, a long variant. Nothing of this is committed. Without network and without the cached file the scenario
`vertical_aozora` skips itself; `vertical_reading` and the Broadway scenarios `vertical_*` need only the synthetic book.

Exact download URLs (what `build-aux/session-tests.sh` fetches when the file is not cached; `NET=0` never downloads):
`alice.epub` = `https://www.gutenberg.org/ebooks/11.epub3.images`, `tiny.epub` = `https://www.gutenberg.org/ebooks/1064.epub.noimages`.
Both are EPUB 3 files generated by Project Gutenberg's ebookmaker; Alice has the cover and the illustrations.

Used by: the real-session UI tests (`build-aux/session-tests.sh`, see `docs/test-notes.md`: Alice for the reader, look-up,
editor and menus, the Masque for the second-book scenario); the real-Kobo sandbox send (`docs/kobo-real-device-report.md`), the ignored test
`devices::tests::sandbox_send_to_a_real_kobo` (`BOOKX_TEST_BOOKS=~/.cache/bookx-testbooks`).

## PDF fixtures

No PDF is committed or downloaded. `bookx_pdf::testpdf` (a small PDF writer: Helvetica/Times/Courier text, links, outline,
page labels, document info, the RC4 40-bit handler for passwords) builds them in memory for the unit tests, and
`cargo run -p bookx-pdf --example make_test_pdfs DIR` writes `story.pdf` (8 pages, outline, roman then arabic page labels,
an internal and an external link, author/title; text original to the test), `locked.pdf` (password `sesame`), `scan.pdf`
(pages without text), `margins.pdf` and `big.pdf` (500 pages) for the Broadway and real-session scenarios. All content is
original test text, so there is no third-party licence. Real-world PDFs (public-domain scans from Wikimedia Commons,
LaTeX papers with two columns) were **not** added: no network fixture is part of the suite yet, which is the main gap in
the evidence for the reflow heuristics (see `docs/pdf-research.md`, "What is not tested"). The truncated and malformed
samples are cut from the generated files inside the tests (`doc::tests::broken_files_are_errors_not_panics`).
