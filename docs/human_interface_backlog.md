# GNOME HIG backlog for the whole app (Guidelines and Patterns), internal

Written 2026-11-20, consolidated from six code and screenshot audits (Sync/Preferences, library and navigation, reader,
editor, Preferences and system surfaces, and the windows opened from the three hamburger menus, §5.6-§5.7) and the owner's decisions (§7). Research and audit when written; waves 7-10 then implemented most rows (the `addressed by wave N` cells say which, and
where; the status of 2026-11-21 is in `docs/remaining-work.md`). **Internal, not for the wiki** (public docs live in `wiki/`, see AGENTS.md §1).

Status column: `open` = not started and the fix is decided, `open (owner-decided)` = the owner decided it, implementation
pending, `owner-decided` = decided by the owner (decision log §7, D1-D6 and the first-round Sync decisions), `needs approval` = a naming, terminology or mental-model choice that must be confirmed first (all collected in §8),
`done` = already aligned (only in §3). The owner's rule for this document: take the optimal fix automatically; ask only for
genuinely ambiguous naming, terminology or user-mental-model changes.

## 1. Sources and limits

`git clone https://gitlab.gnome.org/GNOME/hig.git` is refused (GitLab asks for credentials), so the rendered HIG at
<https://developer.gnome.org/hig/> was read (same content as the source repo). Pages used across the audits:

- Guidelines: `keyboard`, `accessibility`, `adaptive` (Scaling & Adaptiveness), `writing-style`, `ui-icons`, `navigation`,
  `app-naming`, `pointer-touch`. (`ui-styling` and `typography` not read.)
- Patterns, containers: `windows`, `header-bars`, `popovers`, `utility-panes`, `boxed-lists`, `selection-mode`, `grid-views`,
  `list-column-views`; navigation: `sidebars`, `search`, `browsing`, `view-switchers`; controls: `buttons`, `menus`, `switches`,
  `checkboxes`, `radio-buttons`, `drop-downs`, `sliders`, `spin-buttons`, `text-fields`, `overlaid`; feedback: `dialogs`,
  `banners`, `toasts`, `progress-bars`, `placeholders`, `tooltips`. Reference: standard keyboard shortcuts.
- Not read: `tabs`, `notifications`, `spinners`. Most pattern pages were read for their rules (first ~2-4k characters), not every example.
- There is no HIG "Preferences" page; Preferences rules come from Boxed Lists, Switches, Writing Style, Sidebars and Search.

Limits (be honest): the audits were **code and screenshot based; nothing was built or run**. Row counts (dialogs, toasts,
tooltips, untranslated strings) are greps, not a census. 900x600 and 360 px behaviour is judged from breakpoint code and
existing `*_900`/`*_small` scenarios, not from fresh captures; there is no scenario of the main editor window at 900x600.
Several wiki screenshots are stale or will change (the lead's capture run refreshes them; never hand-edit them). Stale now:
`preferences-sync-light.png` (pre-redesign Sync page); `library-main-menu-{light,dark}.png` (still says "Share Library"; also
missing the new names, ellipses and Help; highest priority); `library-device-*` (the file shows the library with the device
banner, not the Device window: name vs content mismatch, the Device window is `device-window-*`). Will change with the rows in
§5.7: `library-statistics-*` (zero state, empty state), `library-saved-searches-*` (no empty state), `library-trackers-*`,
`library-audiobooks-*`, `library-citations-*` (header/buttons move), `library-catalogues-*`, `library-health-*` (if the pages are
restructured), `library-vocabulary-words-*` (header actions), `reader-menu-*` (Help, Properties, labels), `book-map-*` (size, icon),
`reader-goto-*` (error style), `reader-speed-card-*` and `reader-footer-settings-*` (only if they change), `editor-book-menu-*`,
`editor-checkpoints-*`, and `editor-preferences-*` / `preferences-editor-*` (`editor-preferences-*` is retired if WIN-E4 is

Severity: **H** loses data, ships untranslated or broken text, or blocks/confuses a task the owner hit; **M** visible
inconsistency or HIG deviation; **L** polish. (The Sync rows carry the original severities; the other areas had no severity in
their audits, so H/M/L here are derived from their priority lists.)

## 3. What already aligns (done)

### Library and navigation
- Menus: primary menu above the sidebar, `open-menu-symbolic`, primary, no Close/Quit (`library.rs:4238-4243`, `MAIN_MENU`). Not aligned: the tooltip is "Main menu" (lowercase), the group lacks Help and has Copy Diagnostics inside it, and it is not a real menu (§5.6).
- Sidebars: flat list of views with counts, `navigation-sidebar`, accessible name, overlay when narrow with a toggle (`library_sidebar`, `library_tiles_reflow`); the library switcher dropdown in the sidebar header (`library_switcher.rs`).
- Header: title follows the view (Home / Recent / Notes & Highlights + count); sidebar header Add/switcher/Search/Main Menu, content header toggle/spinner/Jobs/title/device/View options; spinner hidden when idle.
- Selection: Escape leaves, count, bottom `ActionBar`, click toggles, right click selects (`library_selection_clicks`); only the header part is missing (see LIB-B1).
- Grid views: unique (generated) cover per item, list alternative, cover-size slider, tested at several widths (`covers.rs`, `library_tiles_reflow`).
- Search: search bar with key capture on the window, "No Results" status page, query hints (`library.rs:4084-4120`); drag and drop to add (`DropTarget`).
- Placeholders: Welcome, No Results, Recent/Favourites empty, Notes "No highlights" with explanation.
- Accessibility: `audit::label` on icon-only buttons, jobs rows, banner chips, sort dropdown, cover-size scale; jobs ring plus text per job with cancel/retry names; tooltips with shortcuts on Add (Ctrl+O), Search (Ctrl+F), Reverse order, Clear selection.
- Responsive: 360x294 minimum, sidebar/details overlays, header compaction (`library_nav.rs` plus unit tests, `library_*_small`); plural-aware `ntr` strings; destructive responses styled; boxed lists for stats, device and health.
- The Continue Reading card is a hero (content), not an `AdwBanner`; its "Also reading" chips have tooltip and label; edition badge and edition list have names; highlight card kebab menu, colour pickers and "Locate again" have tooltips; Export All Annotations uses a folder chooser plus a result toast; Health "Backups, check, trash and history" row has `go-next-symbolic`; Library Health row at the sidebar bottom is fine.
- Boxed-list placeholder pages and confirmation toasts exist for library banners (`library_banner.rs`, offline/read-only).
- Windows opened from the library menu (window audit): Keyboard Shortcuts is the standard `AdwShortcutsDialog`, About is `AdwAboutDialog`, Vocabulary Add/Paste dialogs, the Duplicates empty state and Export as Calibre Library (chooser plus cancellable job) are aligned; all menu dialogs are `adw::Dialog` modal to the main window with Esc and named controls.

### Reader
- Header icon buttons all have tooltip and accessible name (`icon_button()`, `audit::label`; `a11y_audit_reader`, `pdf_a11y_audit`, `comic_a11y`, `vocab_a11y`, `side_a11y`); menu button `open-menu-symbolic`, primary, F10 (tooltip is "Main menu", to be "Main Menu", §5.6.1).
- Contents sidebar is an `AdwOverlaySplitView` (F9, overlays the page, focus moves in, RTL side) in EPUB, comic and PDF; `InlineViewSwitcher` and `AdwStatusPage` placeholders for no contents/bookmarks/notes; PDF has Loading and Error status pages.
- Vocabulary list: `ToggleGroup`, boxed list, "No words here" status page; vocabulary edit dialog is an `AdwDialog` with Cancel/Save, Ctrl+Enter and `EntryRow`s; term popover has names; comic defaults page is all `ComboRow`/`SwitchRow` with descriptions.
- Reader chrome fades and returns on pointer move/tap and stays while a popover, the TTS card or focus is in use (`chrome_busy`, `in_use`, `reader_focus_*`, `chrome_stays_with_read_aloud`).
- TTS player card: `Clamp`, `adw::WrapBox`, group role and name, all controls named, labelled sliders, download progress with text; card at most 360x120 in the session test.
- Touch: selection handles, selection popover swallows pointer/touch so a tap does not clear the selection; note preview is shown in the popover without hover (`note_hover_and_touch`); comic gestures (click zones, pan, pinch, Ctrl+scroll, guided stops) are aligned.
- Keyboard: keyboard-only reading and selection, command palette for every `reader.*` action, rebindable shortcuts with conflict check, RTL arrow mirroring, high-contrast palette, e-ink variants; standard keys F9, F11, Ctrl+F, Ctrl+0/+/-, Alt+Left/Right, Ctrl+W, Ctrl+, , Ctrl+?, F1, Ctrl+O, Ctrl+I present (`shortcuts.rs:868-899`).
- Windows opened from the reader menu: Speed Reading is a non-modal overlay card closing with Esc, Footer Stats popover fits at 900x600, Properties uses `.property` rows, menu accelerator hints follow rebinding (`shortcuts::on_change`).
- Go to dialog: live validation, Go insensitive when invalid, Esc/Cancel; toasts for transient facts; position slider with text label, position label, tooltip and prev/next; PDF page entry with tooltip and Ctrl+G; PDF password dialog; speed-reading card controls named; progress is slider plus percent/page text.

### Editor
- Dialogs: modal choices are `AdwDialog`/`AlertDialog` parented to the window with a `fit_dialog()` cap, shot at 1280x800 and 900x600 with the a11y audit; `alert()` helper has Destructive appearance, default and close response cancel; Save Changes alert is Cancel / Discard (destructive) / Save (suggested, default).
- Header: Save is the only suggested action and insensitive when clean; undo/redo insensitive when unavailable; every header control has a tooltip; hamburger and all tool dialogs have names (83 `audit::label` calls).
- Placeholders: "Select a File" status page; long-line gate status page with suggested pill plus plain "Open Anyway" (the warning is in the visible description).
- Utility panes: right-hand Preview and spelling panes, toggleable; sidebar is an `OverlaySplitView` with `ViewSwitcherBar`; spelling pane has filter, names and a 1,000-row limit.
- Non-destructive tools: Preview/Apply on every tool dialog, every operation is snapshotted first (`run_op`) and rolled back on failure.
- Keyboard: rebindable shortcuts, palette (Ctrl+Shift+P), quick open, F2, Delete, Alt+arrows for the TOC with a drag grip, Ctrl+W/S/F/H/G/N/O/Z, F3/Shift+F3; completion popup tested in the real session; Reports window has Esc and an adaptive 720sp breakpoint.
- Markup menu is paged (a scenario fails above 12 rows at 900x600); dark mode follows the system; boxed lists in Checkpoints, Jacket, A11y form, Manage Fonts and Cover dialogs; Jacket dialog structure; Editor Preferences content (rows only).
- Checkpoints dialog is an `adw::Dialog` with named controls and per-row tooltips; revert creates a redo checkpoint first; the `leave_confirmed` guard for unsaved changes; the Help deep link and working accelerators (Ctrl+O, Ctrl+Alt+Z, F1).
- Dangerous defaults off: `show_whitespace`, `convert_entities`, `check_accessibility` default false.

### Preferences and system
- Preferences is a modal `adw::Dialog` with a parent, sidebar of sections, live search with highlighted rows and a "No Results" status page, Ctrl+F, Esc clears then closes, collapses below 620sp with a toggle (`prefs_search`, `prefs_sidebar`).
- Rows are libadwaita rows (Switch/Combo/Spin/Entry/PasswordEntry/Expander/Action), one control per row nearly everywhere; spin buttons only where the number matters (font size, tab width, ports).
- Accessible names on sidebar rows, search entry and icons per section (`prefs:icons`, `icons_exist`); audit scenarios fail on any unnamed control.
- Confirmations: MCP "Allow changes to my library" (Allow Changes destructive, Cancel default), Remove backup place, backup restore; shared `ui::alert()` is Cancel first with default and close = cancel; shortcut conflict dialog and key-capture dialog.
- Inline status for long actions: MCP status row, TTS test row, backup place "Testing… / Works / Does not work"; backup run has stage + progress bar + Cancel; Calibre export is a cancellable job with "{} of {}" and a toast on errors; Calibre export FileDialog flow has no error dialog.
- Group descriptions explain consequences (Privacy: no telemetry, no account; Metadata: off by default; MCP: local only, token); Privacy page is a good information-only pattern; secrets are masked and a caption says where passwords are stored.
- Welcome placeholder (heading, description, pill buttons), Shortcuts rows activatable with Reset/Clear only when meaningful, patch order buttons insensitive at the ends; reduced-motion, e-ink, RTL and high-contrast scenarios exist (`a11y_high_contrast`, `a11y_rtl_keys`, `a11y_audit_*`, `audio_narrow_900x600`); keyboard Tab/Esc/Ctrl+F in Preferences.

### Sync
- Boxed lists: switch/combo/spin/entry/expander rows, one control per row in Preferences and Editor Preferences; progressive disclosure in two levels (first display plus one collapsed Advanced; status card with one main button); live search finds rows inside collapsed expanders.
- Banners for persistent state (`library_banner.rs`, offline/read-only); toasts for transient feedback and undo; confirmation for destructive actions (`ResponseAppearance::Destructive` in alert dialogs); placeholders for empty states; the Editor Preview is a right-hand utility pane.
