# Keyboard shortcuts

Press ++ctrl+question++ in the app to see the main shortcuts. This page lists them all. Most of them can be changed:
see [Changing shortcuts](#changing-shortcuts).

## Everywhere

| Action | Shortcut |
|---|---|
| Command palette (every command, book and setting) | ++ctrl+k++ or ++ctrl+shift+p++ |
| Preferences | ++ctrl+comma++ |
| Keyboard shortcuts | ++ctrl+question++ |
| Online help | ++f1++ |
| Quit | ++ctrl+q++ |

The command palette lists the commands of the window you are in with their shortcuts. Type a few letters
(`lib` finds *Library Health*), move with ++up++ / ++down++ and press ++enter++. It also finds your books and the rows of
Preferences. See [Accessibility](accessibility.md#command-palette) for the details.

Single letters (++m++, ++t++, ++r++) only work while no text field has the focus. Where these keys come from (Calibre's
viewer, Foliate, KOReader, Okular) and which ones were left out is in the project's notes.

In a book that turns pages right to left (Arabic, Hebrew, manga) ++left++ goes forward and ++right++ goes back, and taps
and swipes are mirrored.

The mouse wheel turns pages; ++ctrl++ + wheel or a pinch zooms; double-click the margin for fullscreen. In the book map the
wheel scrolls the map and ++ctrl++ + wheel changes how much of the book it shows.

Open **Preferences → Keyboard Shortcuts**. Every action of the library, the reader and the book editor (and the application-wide ones)
is listed with its keys.

- **Find** an action with the *Filter shortcuts* field: type part of its name or of its keys (`bookmark`, `ctrl+b`).
- **Change** a shortcut: click its row, then press the new keys. ++escape++ cancels; ++backspace++ removes the
  shortcut.
- If another action already has those keys, Bookx says which one and offers **Swap** (the other action gets the keys
  you replaced), **Take It Away** (the other action loses them) or **Cancel**. Library and reader actions may share
  keys, because they never work in the same window; application-wide actions (Preferences, Quit, the command palette)
  must differ from both.
- The book editor has its own section, **Editor**: its keys only work in the editor window, so they may repeat keys of
  the library or the reader, but two editor actions cannot share a key. Changes apply to every open editor window at
  once and to the shortcut shown in the editor's command palette.
- A plain letter or digit is refused for the library (it would stop you typing in the search field). In the reader a
  plain key is allowed.
- The arrow button on a row **resets** that action; the eraser button **removes** its shortcut; **Reset All** brings
  every default back.
- **Export** and **Import** save your shortcuts to a JSON file and read them back, to move them to another computer.
  An import replaces your shortcuts; unknown actions and invalid keys in the file are skipped and reported, and keys
  that end up on two actions in the same window are flagged.

Changes apply at once to the menus, the [command palette](accessibility.md#command-palette) and the *Keyboard Shortcuts*
window. They are kept in `shortcuts.json` next to the settings file.

!!! note "Limitations"
    - The reader keys that act on a selection (++d++, ++w++, ++t++, ++h++, ++n++, ++enter++, ++shift+arrows++), the
      keys of the editor's file list (++f2++, ++delete++) and the keys the code view itself provides (++ctrl+z++,
      clipboard, ++tab++) are fixed.
    - When the reader's keys for turning pages are changed, the right-to-left mirroring of ++left++ / ++right++ no longer
      applies to the new keys.
    - ++ctrl+r++ in the reader reloads the book; it is not the library refresh.
