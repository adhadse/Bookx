# Code of conduct

Bookx follows the [GNOME Code of Conduct](https://conduct.gnome.org/) in its issues, pull requests, discussions and
translation work. In short:

- Be friendly and patient; be welcoming; be considerate; be respectful.
- Disagree about the work, not about the person. Harassment, insults and discrimination are not accepted.
- Assume good faith, and ask when something is unclear.

To report a problem, write to **hello@adhadse.com** (the maintainer reads it privately). Maintainers may edit or remove
comments, close threads and block people who break these rules.
